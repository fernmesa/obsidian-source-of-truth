# obsidian-source-of-truth

**EN** · [ES](#español)

A Claude Code skill that treats an Obsidian vault (plus optional extra folders) as the single source of truth: search and read notes, update them without duplicating, and plan consolidation of scattered notes into one vault.

## Installation

Copy this folder to `~/.claude/skills/obsidian-source-of-truth/`, or install it as a plugin from your marketplace.

## Usage

- "Search my LeadNicho work"
- "Update the X note with this decision"
- "Consolidate the notes outside the vault" (nothing is moved or copied without confirmation)

## Configuration

Create `obsidian-sources.json` inside your vault. See the "Configuración" section of `SKILL.md`. This file is listed in `.gitignore` and should never be committed.
